Hospital Backgrounds — 196 Pixel Art Scenes
===========================================

196 pixel-art backgrounds. PNG, fully opaque, 128-colour palette. Made for visual
novels, dating sims, RPG cutscenes, and 2D adventure games. Drop them straight
into Godot, Unity, Ren'Py, or RPG Maker.


TWO SIZES ARE INCLUDED

  320x160/    1 pixel = 1 dot. The true resolution of each image. Scale it
              yourself with nearest-neighbour to whatever size you need.

  1280x640/   The same image scaled by a WHOLE NUMBER (4x, nearest-neighbour).
              There is no resampling, so pixels stay square however far you
              zoom in.

  Both folders have all 196 scenes at exactly the same size.


CONTENTS

  Lobbies and waiting halls, wards and private rooms, intensive care,
  operating theatres, labs and imaging, the pharmacy, staff rooms, kitchens
  and canteens, plant rooms and basements, the morgue, rooftops and gardens,
  and an abandoned wing.

  See the store page for the full scene list.
